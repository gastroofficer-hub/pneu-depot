# Pneu Pro Shop

Ahoj, udělej mi webové stránky zaměřené na prodej pneumatik.
Mělo by se jednat o B2C eshop.
Požadavky:
- správa produktů a kategorií
- napojení na běžné platební metody
- napojení na přepravce
- optimalizace pro vyhledávače (SEO)
- zajištění podpory a údržby
